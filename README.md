# Nova Comunicacao Visual

Site institucional da Nova Comunicacao Visual, desenvolvido com Next.js e Tailwind CSS.

## Requisitos

- Node.js 18+
- npm

## Scripts

- `npm run dev` - ambiente de desenvolvimento
- `npm run build` - build de producao
- `npm start` - executar build de producao

## Estrutura

- `src/app` - paginas (App Router)
- `src/components` - componentes reutilizaveis
- `src/data` - conteudo estruturado
- `src/lib` - utilitarios e configuracoes

## Deploy

1. `npm install`
2. `npm run build`
3. `npm start`
